# Cardápio Hamburgueria

Cardápio digital interativo desenvolvido para hamburgueria, com interface dinâmica e responsiva.

## 📌 Descrição

Projeto que utiliza HTML, TailwindCSS e JavaScript para criar um cardápio digital moderno e adaptável, melhorando a experiência do cliente no ambiente digital e facilitando a visualização dos produtos.

## 🔗 Link do Site

- [Acesse o site aqui](https://cardapiohamburgueria.netlify.app/)

## ⚙️ Tecnologias Utilizadas

- **HTML**: Estrutura do cardápio.
- **TailwindCSS**: Estilização rápida e responsiva.
- **JavaScript**: Funcionalidades interativas.

## 🚀 Como Utilizar

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/LGKARD/Cardapio-Hamburgueria.git
   ```

2. **Acesse a pasta do projeto:**

   ```bash
   cd Cardapio-Hamburgueria
   ```

3. **Abra o arquivo `index.html` no navegador para visualizar o cardápio.**

## ⚠️ Observações

- Recomenda-se utilizar navegadores atualizados para melhor compatibilidade.
